# GenomeAtlas — Site Helper Suite

A timelabs-npo product. MIT-licensed original code.

A local-first browser helper for the LAB restriction-modification phylogenomics task: tool registry, independent host-tree and R-M data-flow diagrams, structured probe receipts, file hashing, and delegation review checklists.

## Run and test
Requires Node.js22+; no runtime packages or API keys.

```sh
npm start
npm test
npm run check
npm run test:browser
python3 -B -m unittest discover -s probes/tests -v
```

The browser test uses an installed Chromium-family browser with a temporary headless profile. Imported receipts remain unverified. Local checklist completion is not authorization to run a remote job, merge code, or accept scientific results.

## Evidence boundaries
Parent tests on the authorized Windows endpoint: unit/server tests and actual Edge browser interactions. Copilot receipt tests were independently rerun in Ubuntu; a Windows CRLF fixture mismatch was corrected using explicit LF text handling.

The scientific study remains unfinished:177 inherited LAB assemblies, no Enterococcus, conserved-marker host tree independent of R-M detection. This site does not contain invented biological outputs. NCBI metadata probing is not genome acquisition. Complete computational R-M calls are not biochemical validation.

BioNeMo is a skill toolkit, not proof of a GPU runtime. smarts.bio discovery and small probes have returned, but a checksum discrepancy and subsequent tool404 remain unresolved. Re-probe before accepting new results.

Native ChatGPT Sites publication requires a real supported deployment action and receipt. A GitHub Pages URL or local HTML copy must never be described as native ChatGPT Sites deployment.
