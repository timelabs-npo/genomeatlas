# GenomeAtlas scope

Work only in this repository on the static Site Helper Suite. Read CODEX_TASK.md.
Preserve the supplied accession list byte-for-byte. Original site code is MIT.

- No credentials, personal files, other repositories, auth or native settings changes,
  purchases, background jobs, biological pipeline runs, installs, or sandbox bypasses.
- Do not push, commit, merge, deploy, or change workflows. Parent reviews publication.
- Treat parent reports as attributed reports, distinct from current local checks.
  Availability, declarations, and UI actions are never evidence of execution.
- Unknown/missing/failed R-M results cannot become absence. Raw hits are U;
  curated P requires exact-strain evidence. A cassette is not functional proof.
- No fake tree, fabricated citations, guessed model/session IDs, or native Sites URL.
- Keep all assets local, preserve file:// use and relative deployment paths.
  Render metadata as text, cap and validate imported JSON, and keep the client inert.
- Verify with `python scripts/verify.py`, `python -m unittest discover -s tests -v`,
  Node syntax checks, and the browser smoke script when a browser is available.
  Record actual commands, exit codes, and results in evidence/. Never label an
  unrun script PASSED. Leave edits uncommitted for parent review.
