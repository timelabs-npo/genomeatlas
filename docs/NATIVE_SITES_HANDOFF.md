# Native ChatGPT Sites handoff

## Current status

This repository does **not** contain a native ChatGPT Site deployment receipt.
The static source in `docs/` is portable HTML/CSS/JS and may be reviewed or hosted separately, but it must not be relabeled as a native ChatGPT Site.

## What would be needed before a native-site claim

1. A real native ChatGPT Site manifest or deployment receipt
2. Reviewer confirmation that the receipt maps to this exact source revision
3. A documented boundary between portable source hosting and any native-site packaging step
4. An explicit note that no private credentials, local paths, or raw agent histories are published

## What this handoff intentionally avoids

- no deployment claim
- no DNS or hosting changes
- no GitHub Pages equals native-site equivalence
- no fabricated receipt identifiers
