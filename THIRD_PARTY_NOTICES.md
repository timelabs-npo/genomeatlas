# Third-party boundaries

The existing root MIT LICENSE is retained unchanged and applies to original GenomeAtlas code and original documentation. It does not relicense third-party software, documentation, data, models, weights, services or trademarks.

The only bundled upstream data is the small RefSeq accession identifier list from the public `serg-alexv/genomeops-atlas` source. Its exact commit and SHA-256 are in `docs/data/source-manifest.json`. Prior public journals are summarized in original words and linked to immutable source commits. Raw journal bytes remain in a gitignored local cache; no private manuscripts, full account registry, vendor documentation, model files or weights are imported.

- NVIDIA BioNeMo Agent Toolkit: the parent reports plugin version 0.1.0 and two skill reads. No plugin or skill content is copied here. Review the applicable toolkit/plugin, model and service terms separately. [NVIDIA BioNeMo upstream](https://github.com/NVIDIA/bionemo-framework) is a reference link, not a blanket license for all BioNeMo components.
- AlphaGenome: links and conceptual role only. [AlphaGenome upstream](https://github.com/google-deepmind/alphagenome) is the place to inspect current code and access terms. Repository code licensing does not imply permission for every model, weight, dataset, hosted endpoint or use.

No vendor licensed content is embedded in SVGs or interface text. The diagrams are original workflow schematics, not scientific outputs.
